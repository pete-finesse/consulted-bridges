# Bridge scorecard v2

*Replaces the criteria in `docs/scorecard/v1.md`, after the review in `docs/reviews/review_scorecard.md`. Script: `src/consulted_bridges/legacy/bridge_card2.py`; sentences: `src/consulted_bridges/questions/v2.py`. The thresholds were fixed before this run.*

## The setup, in one paragraph

- **The question:** each question has a hidden middle step, the **bridge**. "How many legs do the animals that spin webs have?" needs *spider* to get *Eight*.
- **P:** the model's probability of the right answer.
- **The edit:** we remove one word's J-lens direction from the model's internal state, from the question's first word to the end of the prompt, in a 6-layer window (layers 0–5, 3–8, …, 27–31).
- **Drop:** 1 − P after ÷ P before. 1 means the answer is gone; 0 means nothing changed.
- **How each result reads:** *Remove "spider" in layers 9–14 → P("Eight") goes 0.88 → 0.00. Drop 1.00.*

## What changed from v1, and why

| v1 problem (from the review) | v2 fix |
|---|---|
| "Bystander" couldn't tell "not used" from "the edit can't reach it" | **Gate 4:** in a one-hop question whose answer *is* the bridge, the edit must remove the bridge |
| The best window often fell in late layers, where the model is already writing the answer | **Gate 3** finds the **answer onset**: the first window where removing the answer's own direction kills it. Every test then only counts windows that end before it |
| No noise floor; some prompts break under any edit | **Beats noise:** compare with 12 everyday words of matching strength |
| On-topic "unrelated" controls | Everyday nouns (table, chair, …) instead of the prompt's own lens words |
| Broken word pieces (" F" for Funchal) | **Gate 2:** every edited word must be a single token; others are skipped and reported |
| Facts the model didn't actually know | **Gate 1:** the model must answer the two-hop question and both one-hop questions |
| Effects spread over many layers were missed | **Spread out:** also remove over layers 8–23 and over all layers |
| "Own part" and swap tests decided verdicts, but they're confounded | Now reported only. Swap expectations come from the model's own answers ("How many legs does a crab have?" → Eight) |
| "After reading" saturated | Replaced by **comes first**: the bridge must matter before the answer does |

## Gates: can this question be tested at all?

| Gate | Passes when |
|---|---|
| 1 · Knows it | The model answers the two-hop question right, and both one-hop questions ("Which animals spin webs?", "How many legs does a spider have?") |
| 2 · Clean words | Every edited word is one token |
| 3 · Answer onset | Removing the answer's own direction kills P in some window; the first such window is the answer onset |
| 4 · Edit reaches the bridge | In the one-hop question whose answer is the bridge, removing the bridge (in a window before the answer onset) drops P(bridge) by ≥ 0.5 |

If the answer onset is in the very first window, the answer is present from the start. Then there's no layer where the bridge could act first, and the verdict is **Answer from the start**.

## Tests

All tests use only windows that end before the answer onset.

| # | Test | Question it answers | Pass |
|---|---|---|---|
| 1 | Needed early | Does removing the bridge kill the answer? | reported |
| 2 | Beats noise | Needed early, minus the biggest drop from 12 everyday words | ≥ 0.5 |
| 3 | Comes first | The bridge's first window with drop ≥ 0.5 starts at least 3 layers before the answer onset | yes |
| 4 | Beats own kind | Needed early, minus the drop from removing another word of its kind with the same answer (Vienna for Salzburg; tick for spider) | ≥ 0.3 |
| 5 | No collateral damage | The same edit on "chemical symbol for gold" and "largest planet" | drop ≤ 0.1 |
| 6 | Spread out | Removal over layers 8–23 and over all layers | reported |
| 7 | Own part | Removing only the part of the bridge not shared with the answer | reported |
| 8 | Swaps follow | Swapping in another word gives that word's own answer (not counting the fallback) | reported |
| 9 | Same-answer swap | Swapping in a word with the same answer keeps it | reported |

## Verdicts

| Verdict | Rule |
|---|---|
| **Consulted bridge** | Gates pass; beats noise; comes first; no collateral damage; beats its own kind |
| Consulted (kind not checked) | As above, but there's no same-kind word to compare with |
| **Category effect** | Needed and first, but another word of its kind does the same (the "Austrian place" case) |
| **Tangled** | Beats noise, but doesn't act before the answer does |
| **Spread out** | Short windows don't matter, but removal over 16 or all layers drops ≥ 0.5 |
| **Bystander** | The edit reaches the bridge, yet every removal drops < 0.2 |
| **Untestable** | A gate fails; the card says which |
| Unclear | Anything else |

## The sentences

There are 28, grouped as before:
- **E · description riddles,** like spider: spider, bee, penguin, elephant, apple, banana, carrot.
- **A · landmark → country → capital:** Colosseum, Kremlin, Christ the Redeemer, CN Tower.
- **B · person → birth city → country:**
  - B1, born in the capital: Mishima, Piaf, Loren;
  - B2, famous: Mozart, Federer, Messi, Gates, Maldini;
  - B3, born abroad: Keanu Reeves, Bieber.
- **C · university → city → country:**
  - C1, capital: Charles University, Karolinska, Tsinghua;
  - C2, other cities: Fudan, Johns Hopkins, York University, McGill.

Each has a prediction written before running.

**The two consulted bridges:**
- **Spider:** remove "spider" in layers 15–20 → P("Eight") goes 0.88 → 0.00. Drop 1.00.
  - It matters from layer 9; the answer only from layer 21.
  - Noise floor 0.05. Removing "ticks" (also eight legs) drops it only 0.05.
  - Removing only spider's own part (not shared with "Eight") still gives 1.00.
  - 3 of 5 swaps give the swapped animal's own leg count.
- **York University:** remove "Toronto" in layers 9–14 → P("Canada") goes 0.99 → 0.35. Drop 0.65.
  - It matters from layer 9; the answer from layer 15. Noise floor 0.00. Removing "Vancouver" drops it 0.02.
  - **Caveat:** removing only Toronto's own part does nothing (0.01), and 0 of 8 swaps follow. The part of "Toronto" that matters is what it shares with "Canada". So this is a weaker case than spider.

**The bystanders are now trustworthy.**
- **The edit can reach the bridge:** removing "Tokyo" kills "Tokyo" as the one-hop answer (Mishima, 0.99).
- **But the answer doesn't need it:** removing it does nothing to "Japan", even over all layers.

**What failed most:** gate 4. For country bridges, and for several cities (Prague, Baltimore, Montreal), removing the J-lens direction doesn't remove the word even in the one-hop question, in the layers before the answer forms. One J-lens direction is not how the model holds those words there.
