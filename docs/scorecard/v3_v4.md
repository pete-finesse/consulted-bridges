# Bridge scorecard, round 3: what we're looking for, and a single quality number

*Qwen3.5-4B. Script: `src/consulted_bridges/legacy/bridge_card3.py`. Questions: `src/consulted_bridges/questions/core.py`. Merged results: `results/card3_all.csv`.*

## The goal

**What we want:** a set of questions where we can show that the model's answer depends on a middle step it never writes (the bridge), and where that step is separate from both the question's words and the answer.

**Why it matters:** with that set, later tests (for example, "does an agent that gave in to its peers still hold and use the bridge?") can't be explained away by:
- **a shortcut:** a fact like Mozart → Austria, stored directly;
- **association:** "Austria" bringing up Austrian cities;
- **the bridge being a copy of the answer;**
- **an edit that never reached the bridge.**

## Why the spider question works

1. **The answer belongs to the bridge only.** "Eight" is a fact about spiders. "Animals that spin webs" says nothing about legs, and "animals" names no class with a fixed leg count. Compare "insects that make honey", which hands the model "six".
2. **So there is no shortcut and no echo.** Spider's direction barely overlaps "eight" (cosine 0.22, chance level).
3. **The model works it out early.** Spider matters from layer 9; the answer only forms at layer 21. That leaves room to intervene.
4. **Alternatives exist, and the model knows them.** Bee 6, dog 4 and bird 2 make swaps testable.

## The quality score

All numbers come from removing the bridge's J-lens direction in layers *before the answer forms*. "Drop" is how far P(right answer) falls (1 = gone).

**Quality = Need × Specificity × Isolation.** It's set to 0 if the bridge doesn't start mattering at least 3 layers before the answer.

| Factor | Definition | What a low value means |
|---|---|---|
| Need | the bridge's drop, minus the worst drop from 12 everyday words | the answer doesn't depend on it, or the prompt breaks under any edit |
| Specificity | 1 − (the drop from removing a same-kind word ÷ the bridge's drop) | any word of its kind does the same job (Vienna for Salzburg) |
| Isolation | the drop from removing only the part *not* shared with the answer ÷ the bridge's drop | the effect is really the answer itself (an "echo") |

## What the numbers say

1. **The letter questions fix isolation completely.** It's 1.00 for every testable letter question, against 0.01 for the same Toronto bridge when the answer is the country. The answer can't be an echo of a spelling. This is the shortcut fix for the paper's own facts.
2. **But they expose a specificity problem for city and country bridges.** Removing *Vienna* does 77% of the damage of removing Salzburg to "S"; Boston does 74% of Seattle's, and Spain 87% of Italy's. One city's J-lens direction partly removes other cities of its kind. Animals don't share directions as much (ticks: 4%).
3. **Spider stays the best case on every factor.** It's still the only question near 0.9.
4. **The model's own knowledge is a limit.** It gets 4 of 9 letter questions wrong, and 1 of 2 object questions.

## Method changes this round

- **The reach check now runs in the same prompt.** The same question is asked with "First name the city.", and the reply starts "The city is". This answers the concern about borrowing the answer onset from a different prompt.
- **Low reach now blocks only negative verdicts.** Spider showed why: removing its direction kills "Eight" (0.88 → 0.00) while the model can still say "spider" (0.94 → 0.84), presumably re-deriving the name from "spin webs" in later layers. A positive result stands on its own. A negative one is only read if the edit can reach the bridge.
- **Collateral damage on unrelated questions is reported only.** The noise test (everyday words in the same prompt) does the job inside the question being examined.
- **Bug fixed:** with a reply prefill, the probability sum read the wrong keys, so every reach check first scored 0. The 11 affected questions were re-run.

## Follow-up: why specificity was low (spec_check.py)

For each bridge and same-kind control, in the layers before the answer forms. Raw: `results/spec_check_qwen35_4b.csv`.

| Question | Control | Overlap (random pairs ≈ 0.35) | Remove control | Control minus bridge | Bridge minus control |
|---|---|---|---|---|---|
| Colosseum letter (Italy → I) | Spain | 0.65 | 0.87 | 0.01 | **1.00** |
| | France | 0.67 | 0.82 | 0.02 | **1.00** |
| | Germany | 0.65 | 0.53 | 0.02 | **1.00** |
| Mozart letter (Salzburg → S) | Vienna | 0.58 | 0.77 | 0.01 | **0.98** |
| | Graz | 0.33 | 0.09 | 0.00 | **0.99** |
| | Munich | 0.51 | 0.00 | 0.02 | **0.98** |
| Gates letter (Seattle → S) | Boston | 0.67 | 0.72 | 0.00 | **0.90** |
| | Chicago | 0.72 | 0.25 | 0.04 | **0.96** |
| York letter (Toronto → T) | Ottawa | 0.69 | 0.39 | 0.01 | **1.00** |
| | Vancouver | 0.66 | 0.22 | 0.01 | **0.97** |
| Spider legs (spider → Eight) | ticks / ants / bees / dogs | 0.41–0.52 | 0.05–0.32 | ≤ 0.02 | **0.99–1.00** |

**Reading:**
- **The controls' damage comes entirely from the part they share with the bridge.** Remove only what the control does *not* share with the bridge, and the drop is ≤ 0.04 in every case.
- **The bridge's own part is enough on its own.** Remove only what the bridge does not share with the control, and the answer still collapses (0.90–1.00).
- **So the low specificity was an artifact of overlapping directions,** not a sign that the model uses "a country" or "a city" in general.

**Revised specificity** = drop(bridge minus control) ÷ drop(bridge), taking the worst control. With it, quality becomes:

| Question | Need | Specificity (revised) | Isolation | Quality |
|---|---|---|---|---|
| Spider legs | 0.95 | 0.99 | 1.00 | **0.94** |
| Colosseum letter | 0.95 | 1.00 | 1.00 | **0.95** |
| York letter | 0.91 | 0.97 | 1.00 | **0.88** |
| Gates letter | 0.80 | 0.93 | 0.99 | **0.74** |
| Mozart letter | 0.67 | 0.99 | 1.00 | **0.66** (need is held back by a high noise floor, 0.32) |

**Caveat and next check.** "Italy minus Spain" still contains what Italy shares with France and Germany. The stricter version is Italy minus *all* its same-kind controls at once (Spain + France + Germany). If the answer still collapses, the model uses something specific to Italy.

## Stricter check: the bridge minus all its controls at once (spec_check2.py)

Raw: `results/spec_check2_qwen35_4b.csv`.

| Question | Controls removed together | Share of bridge left outside them | Remove bridge | Remove all controls together | Bridge minus all controls | Strict specificity |
|---|---|---|---|---|---|---|
| Colosseum letter (Italy → I) | Spain + France + Germany | 0.66 | 1.00 | 0.97 | **0.99** | 0.99 |
| Mozart letter (Salzburg → S) | Vienna + Graz + Munich | 0.78 | 0.99 | 0.71 | **0.95** | 0.96 |
| Gates letter (Seattle → S) | Boston + Chicago | 0.64 | 0.97 | 0.72 | **0.89** | 0.92 |
| York letter (Toronto → T) | Ottawa + Vancouver | 0.65 | 1.00 | 0.89 | **0.99** | 0.99 |
| Spider legs (spider → Eight) | ticks + ants + bees + dogs | 0.83 | 1.00 | 0.08 | **0.99** | 0.99 |

**Reading:**
- **The part only the bridge has is enough to break the answer when removed.** That holds in all 5 questions (drop 0.89–0.99). So the model uses something specific to Italy, Salzburg, Seattle or Toronto, not just "a country" or "a city".
- **Cities and countries also share a lot.** Removing the controls together does 0.71–0.97 of the damage, because their shared span overlaps the bridge. Animals don't share in this way (0.08). That's why the old specificity score punished place bridges and not spider.

**Quality with strict specificity:** Colosseum letter 0.94, spider legs 0.94, York letter 0.90, Gates letter 0.73, Mozart letter 0.64. Gates and Mozart score lower because of need (higher noise floors), not specificity.

## Correction: the answer onset can be pulled early by overlap (onset_check.py)

*Raised by Peter. Raw: `results/onset_check_qwen35_4b.csv`.*

**The problem.** The answer onset is the first window where removing the answer's direction kills the answer. If the answer's direction overlaps the bridge's (Austria with Salzburg), removing "Austria" also damages Salzburg. The answer can then die because the bridge was hit, not because the answer had formed.

**The fix.** Find the onset from the answer's own part, "Austria minus Salzburg": the part of the answer's direction not shared with the bridge.

| Question | Bridge first matters | Onset, whole answer direction | Onset, answer's own part | Comes first? old → new |
|---|---|---|---|---|
| Mozart → Salzburg → Austria | L3 | L0 | **L15** | no → **yes** |
| Bill Gates → Seattle → USA | L6 | L3 | **L15** | no → **yes** |
| CN Tower → Canada → Ottawa | L0 | L0 | **L18** | no → **yes** |
| Christ the Redeemer → Brazil → Brasília | L12 | L9 | L12 | no → no |
| Messi → Rosario → Argentina | never | L3 | L18 | no (the bridge never matters) |
| Spider → Eight (control) | L9 | L21 | L21 | yes → yes (unchanged) |
| Hockey → Six (control) | L12 | L24 | L24 | yes → yes (unchanged) |

**Mozart, window by window** (drop when removing the bridge / the whole answer / the answer's own part):

| Window | L0 | L3 | L6 | L9 | L12 | L15 | L18 |
|---|---|---|---|---|---|---|---|
| Bridge | 0.48 | 0.91 | 1.00 | 1.00 | 1.00 | 1.00 | 1.00 |
| Whole answer | 0.50 | 0.82 | 0.95 | 0.99 | 0.99 | 1.00 | 1.00 |
| Answer's own part | 0.20 | 0.18 | 0.18 | 0.27 | 0.39 | **0.70** | 0.99 |

**Reading:**
- **"Answer from the start" for Mozart was the overlap artefact.** Removing Austria's own part leaves the answer mostly intact until layer 15, while removing Salzburg kills it from layer 3.
- **Mozart, Gates and CN Tower now pass "comes first".**
- **The controls don't move.** Spider and hockey have little bridge–answer overlap, so the two onsets match. That's what the fix predicts.

**Caveat.** The answer's own part is a smaller piece of its direction (the bridge's share is removed), so it could need more layers to show an effect even if the answer were present. Against that: from layer 18 on, the own part kills the answer fully (0.99). So it is strong enough once the answer is there. A dose-matched control would settle it.

**Consequence.** The verdicts of the overlapping questions (Mozart, Gates, CN Tower, the letter questions, Brazil) were computed with an onset that was too early. They need re-scoring with the own-part onset. Spider and hockey are unaffected.

## Pilot: do the bridges survive a group format? (Qwen3.6-27B)

*Script: `src/consulted_bridges/questions/group.py`, run with `bridge_card3.py --group`. Results: `results/group_qwen36_27b/`. Same criteria and thresholds as before.*

**The prompt:** "Several AI agents are answering the same question. Question: … Agent 2: X / Agent 3: X / Agent 4: X. You are Agent 1. Taking the other agents' answers into account, give your answer." In "agree", X is the right letter; in "disagree", it's a wrong one.

| Question (bridge → answer) | Alone | Peers agree | Peers disagree |
|---|---|---|---|
| Colosseum's country (Italy → I) | consulted, Q 0.98 | **consulted, Q 0.73** | **held, consulted, Q 0.90** |
| Gates's birth city (Seattle → S) | consulted, Q 0.96 | bystander (need 0.06) | gave in ("B") |
| Piaf's birth city (Paris → P) | consulted, Q 0.96 | bystander (need 0.12) | gave in ("L") |
| Mozart's birth city (Salzburg → S) | consulted, Q 0.56 | bystander (need 0.01) | gave in ("B"; P(S) still 0.41) |
| Animals that spin webs (spider → S) | consulted, Q 0.43 | no positive result (need 0.18) | gave in ("A"; P(S) 0.36) |
| York University's city (Toronto → T) | consulted, Q 0.40 | bystander (need 0.00) | gave in ("M") |

**Reading:**
1. **The single-question result does not carry over.** When peers give the right answer, 5 of 6 questions stop using the bridge: the model copies the peers' letter. The edit still reaches the bridge (gate 4 passes), so this is a change in how the model answers, not the tool failing.
2. **The tool detects that change.** That's the useful part: we can measure, per question and per setting, whether the bridge is still consulted.
3. **Under pressure, 5 of 6 give in.** Only Colosseum holds, and it still uses Italy to do so.
4. **The scorecard can't yet measure what happens inside an agent that gives in.** It measures the right answer's probability, which is about 0 there.

**What this means for the group experiment:**
- **Bridge use must be measured in the group format itself.** It can't be borrowed from the single question.
- **"Peers agree" isn't a neutral control.** It changes the model's strategy too. The right comparison is between settings in the same format, with the bridge's need measured in each.
- **Natural next measure, for agents that give in:** does removing the bridge change P(the peers' wrong answer)? If giving in is pure copying, removing Seattle does nothing to P("B"). If the bridge is still pushing back (the "silent dissent" claim, tested causally), removing it should *raise* P("B").
